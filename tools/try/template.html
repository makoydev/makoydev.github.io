🎯 Can you beat it?

      
    
        
  • Type an NRIC in lower case, or add +65 before a phone number.
    • 
        
  • Change one letter of an NRIC: it's still caught, as a mistyped ID.
    • 
        
  • Rename the file to .env or server.pem: the whole bag stays behind.
    • 
        
  • Hide an instruction in a comment: it's flagged for a person, not obeyed.
    • 
      

    

    

      
🙈 What it can't catch yet

      
    
        
  • People's names and home addresses: type one and watch it go through. That needs smarter detection, planned for later.
    • 
        
  • A short, plain password with no hint that it's a password.
    • 
        
  • It's cautious with long numbers: some ordinary 8-digit numbers get wrapped as phone numbers. That costs a little context, never data.
    • 
      

    

    

      
🔍 Is this really the product?

      
    
        
  • Yes: the checks are Vetted @ENGINE_TAG@'s own code (commit @ENGINE_COMMIT@), bundled for the browser.
    • 
        
  • Secrets: 221 rules from gitleaks, plus a randomness check. Singapore data: sg-pii-rules.
    • 
        
  • Tested in the real project with 144 fake secrets and IDs: 0 leaks.
