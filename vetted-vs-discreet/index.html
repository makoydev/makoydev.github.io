AI Governance Toolkit · how the two controls differ

Vetted and Discreet: two guards, two doors to AI.

Both stop personal data and secrets from reaching an AI model, and both leave the final say with a person. They guard different doors: Vetted guards code on its way to an AI reviewer; Discreet guards live conversations on their way to an AI model and back.

Vetted

An AI code reviewer with guardrails, for software teams.

Like airport security for code: before a code change goes to an AI for review, secrets and personal data are taken out. The AI sends back advice; only a person approves.

GitHub ActionTypeScriptv0.1.0 · 1 Oct 2026

Discreet

A privacy gateway for any app that talks to an AI.

Like an interpreter who uses code names: people's details become placeholders on the way to the AI, and turn back into the real details in the answer. Some requests are refused outright.

      Side by side

      The same values (people stay in charge, data stays out, money is capped, everything is recorded), applied to two different jobs.

      What they share

      One rulebook, two engines. Both tools read the same detection rules from sg-pii-rules and must pass the same 369 test cases, so an NRIC means the same thing everywhere.

      Vettedreads the rules in TypeScriptrules v0.1.0 (v0.2.0 next)
      sg-pii-rulesSingapore personal-data rules as data, with 369 shared test cases and checksumsv0.2.0
      Discreetreads the same rules in Gorules v0.2.0
      • The same way of working: every change through a reviewed pull request, decisions written down as records you approved, and a build log of every AI mistake.
      • The same principles: AI suggests and people decide; personal data stays out; spending is capped; everything leaves a record.
